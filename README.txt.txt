Project: Milestone 1 - Personal Portfolio

Pages Created:
- index.html (Home page)
- projects.html (Projects page)
- contact.html (Contact page)

Notes on Structure:
This version uses a simplified HTML structure for learning purposes

Required Elements Location:
- List: On index.html (Skills & Interests) and contact.html.
- Table: On projects.html to list my academic projects.
- Special Character: The em-dash special character (&mdash;) is used to separate the navigation links at the top of each page.

Project: Milestone 2 - CSS Styling

Pages Styled: index.html, projects.html, contact.html

The color scheme that I chose is a bold theme using royal blue for the background, white for the main text, and a bright yellow (#FFBF00) as an accent for links and headings. The font used across the entire site is Verdana for its clean readability. No issues that I'm aware of. 

Project: Milestone 3 - JavaScript Interactivity

Feature Implemented: Time-Based Greeting
How to use: Load the index.html (Home) page. The "Welcome!" heading will automatically change to "Good Morning," "Good Afternoon," or "Good Evening" based on the time of day.
JavaScript Concepts Applied:
- Variables (const, let)
- Functions (traditional)
- Conditionals (if/else if/else)
- Event Listeners (DOMContentLoaded)
